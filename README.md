# 🤖 MYRA — AI Voice Companion

MYRA is a futuristic AI Voice Companion built for Android using **Kotlin**, **MVVM**, and **Google Gemini Live WebSocket API**. It delivers real-time voice conversations, intelligent task execution, customizable personalities, and a modern sci-fi interface inspired by premium AI assistants.

# 🚀 Getting Started

## Requirements

* Android Studio (Latest Stable)
* Android SDK 34+
* Kotlin
* Gemini API Key
* Android Device (Android 8.0+)

---

## Installation

1. Clone the repository.
2. Open the project in Android Studio.
3. Sync Gradle.
4. Add your Gemini API Key in Settings.
5. Build and Run.
